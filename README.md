# BNPL AI Support — Observability Dashboard

A monitoring dashboard for the Tabby BNPL Customer Support AI Agent, tracking real usage metrics from its conversation logs — built as a companion piece to demonstrate production AI monitoring, not just AI building.

## What It Tracks
- Total questions handled
- Escalation rate (AI → human handoff)
- Average response time
- Estimated API cost (based on token usage)
- Daily question volume trend
- Response type breakdown (answered vs escalated vs errored)
- Common topic categories (rule-based keyword classification)
- Full recent conversation log table

## Tech Stack
- Python
- Streamlit
- Pandas
- Matplotlib

## How It Works
The dashboard reads a `conversation_log.csv` file (generated by the [Tabby BNPL Support Agent](https://github.com/Hashimkhan303/tabby-bnpl-support-agent)) and computes live metrics and visualizations from real interaction data — no sample or fake data used.
